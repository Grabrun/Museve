## 审计核对 + 全量修复（Museve）

输入：`docs/museve-audit-2026-11-04.md`（外部深度审计，22 项）。

### 核对结论（供后续参考）

- 22 项**全部有真实代码依据**，行级定位几乎全中，但审计本身有偏差：
  - H1 子结论错误：DOMPurify 的 URI 校验独立于 `ALLOWED_ATTR`，显式白名单**不会**放行 `javascript:`（`ALLOW_UNKNOWN_PROTOCOLS` 默认 false）。
  - M3 计数：CSRF 覆盖是 6/8 端点，不是「8/9」；`auth.php` 也缺。
  - L2：表定义重复是 5 处（4 冗余），「注释全写里程碑表」不成立。
  - L3：每请求 DDL 是 11 条（7 张唯一表），不是 8 条。
  - L4：`CHAR_LENGTH` 是字符数不是字节数。
  - 供应链：`style.css` 是 525 行手写令牌，**零** Tailwind 工具类；模板 19 个文件、3000+ 处依赖 CDN。迁移成本远高于审计暗示。
- 审计漏报：`docs/` 随 rsync 进 webroot（审计报告本身可下载）、sitemap Host 头注入、`$_FILES['type']` 客户端 MIME 回退、关于页宣传不存在的 PHPMailer、设置页 `maintenance_mode` 单选框缺 `setting-input` 类导致永不提交。

### 关键实现决策

- **服务端净化**：`includes/html-sanitizer.php`，DOMDocument + 标签/属性/协议白名单 + style 属性级过滤；`read.php` 与 `api/articles.php` 输出侧再兜一层（幂等）。历史数据用 `tools/resanitize-articles.php` 清理。
- **锁定策略**：主锁 IP+账号（消除「刷错密码锁死站长」），次锁同 IP ×4 阈值；`login_attempts` 每次失败顺带修剪 1 天前记录。
- **设置接线**：新增 `getSettings()/getSetting()/assetUrl()`，`DEFAULT_SETTINGS` 成为唯一键白名单，`settings` API 只写白名单键并做值归一化。
- **前端本地化**：Tailwind 预编译（32KB）、Alpine/Pjax/DOMPurify/TinyMCE/Phosphor 落 `resources/vendor/`，运行时只剩 Google Fonts 一个第三方请求。TinyMCE 用 `images_upload_handler` 传 CSRF。
- **建表优化**：`SHOW TABLES` 探测 + 只补缺失表，取代每请求 11 条 DDL。
