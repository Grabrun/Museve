## 纯净部署包（Museve）

### 背景
用户要求「再试推送 + 打包纯净部署包」。推送此前被本机代理按主机拦截：
`github.com` CONNECT 返回 502，但 `api.github.com`/`codeload`/npm registry 均 200。
实测为**间歇性**（6 次探测 2 次 200），改成 12 次重试循环后第 1~2 次即成功。
结论：这类 502 不是仓库或凭据问题，重试即可，不需要改 remote 或降级协议。

### 打包器 tools/pack.mjs
- 本机 Git Bash 无 `zip`/`rsync`，改用 Node 内置 `zlib` 自写 ZIP（自实现 crc32、
  local/central header、EOCD），产物用 `unzip -t` 校验——零新增依赖、不依赖网络。
- 取舍规则：**顶层白名单**（index.php/404.html/robots.txt/sitemap.php + admin api
  includes sections resources tools uploads）起步，再叠黑名单；任何新增开发产物默认不入包。
- 内置预检：命中 `includes/config.php`、node_modules、docs、package.json、nginx.conf 直接拒绝出包。
- 命名用**本地时间**（UTC 会让凌晨发布的包看起来早一天）+ git short sha。
- `npm run pack` 入口；`dist/` 已 gitignore。
